## What the Code Does

This is a **bubble sort** algorithm. It sorts a list of numbers in **ascending order** (smallest to largest) by repeatedly comparing adjacent elements and swapping them if they're in the wrong order.

### How it works, step by step:

1. **Outer loop** (`i`): Controls how many passes are made through the list. After each pass, the largest unsorted element "bubbles up" to its correct position at the end.
2. **Inner loop** (`j`): Walks through the list, comparing each element with its neighbor.
3. **Swap**: If the left element is greater than the right element, they are swapped.
4. The process repeats until the list is fully sorted.

## Tracing with input `[3, 1, 2]`

**Pass 1** (`i = 0`):
- Compare `3` and `1` → `3 > 1`, swap → `[1, 3, 2]`
- Compare `3` and `2` → `3 > 2`, swap → `[1, 2, 3]`

**Pass 2** (`i = 1`):
- Compare `1` and `2` → `1 < 2`, no swap → `[1, 2, 3]`

**Pass 3** (`i = 2`):
- Inner loop range is empty (`len(xs) - 1 - 2 = 0`), so nothing happens.

## Result

The function returns **`[1, 2, 3]`** — the input list sorted in ascending order.

> **Note:** The function modifies the original list in place (it doesn't create a new list), and then returns that same list.
