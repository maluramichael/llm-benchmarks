## What the Code Does

This is a **bubble sort** algorithm. It sorts a list of numbers in **ascending order** (smallest to largest) by repeatedly comparing adjacent elements and swapping them if they're in the wrong order.

### How it works, step by step:

1. The outer loop (`for i in range(len(xs))`) controls how many passes are made through the list.
2. The inner loop (`for j in range(len(xs) - 1 - i)`) compares each pair of adjacent elements.
3. If the left element is **greater than** the right element, they are **swapped**.
4. After each full pass, the largest unsorted element "bubbles up" to its correct position at the end, so the inner loop gets shorter each time (`len(xs) - 1 - i`).

## Tracing with input `[3, 1, 2]`

**Pass 1** (`i = 0`, inner loop runs for `j = 0, 1`):
- `j = 0`: Compare `3` and `1` → `3 > 1`, so swap → list becomes `[1, 3, 2]`
- `j = 1`: Compare `3` and `2` → `3 > 2`, so swap → list becomes `[1, 2, 3]`

**Pass 2** (`i = 1`, inner loop runs for `j = 0`):
- `j = 0`: Compare `1` and `2` → `1 < 2`, no swap → list stays `[1, 2, 3]`

**Pass 3** (`i = 2`, inner loop runs for `j = -1` → no iterations):
- Nothing happens.

## Result

The function returns **`[1, 2, 3]`** — the input list sorted in ascending order.
