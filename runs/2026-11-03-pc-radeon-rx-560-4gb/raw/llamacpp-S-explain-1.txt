This code implements the **Bubble Sort** algorithm.

### What it does in plain English:
It goes through the list multiple times, looking at adjacent pairs of numbers. If it finds a pair where the first number is larger than the second, it swaps them. This process repeats until the list is completely sorted in ascending order (smallest to largest).

Think of it like bubbles rising to the top: larger numbers "bubble up" to the end of the list, while smaller numbers sink to the front.

### What it returns for the input `[3, 1, 2]`:
1.  **First Pass:**
    *   Compare 3 and 1: $3 > 1$, so swap them. List becomes `[1, 3, 2]`.
    *   Compare 3 and 2: $3 > 2$, so swap them. List becomes `[1, 2, 3]`.
2.  **Second Pass:**
    *   Compare 1 and 2: $1 < 2$, no swap.
    *   Compare 2 and 3: $2 < 3$, no swap.
3.  The list is now sorted.

**Final Output:**
```python
[1, 2, 3]
```
