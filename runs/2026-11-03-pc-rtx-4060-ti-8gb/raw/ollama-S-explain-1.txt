This code implements the **Bubble Sort** algorithm. It sorts a list of numbers in ascending order by repeatedly swapping adjacent elements if they are in the wrong order.

### How it works (Plain English):
Imagine you have a row of people, and you want them lined up from shortest to tallest. You walk down the line looking at neighbors:
1. If the person on the left is taller than the person on their right, you swap them so the shorter one is now on the left.
2. You keep walking down the line until you reach the end.
3. Then, you start over from the beginning of the line again.
4. Because the tallest person "bubbles up" to the end during each pass, you don't need to check them in future passes. You can stop checking a little earlier each time.

The code does exactly this: it loops through the list multiple times (`i` represents the pass number), and inside those loops, it checks every pair of neighbors (`j` and `j+1`) and swaps them if needed.

### Execution for Input `[3, 1, 2]`:

Let's trace the steps manually:

**Initial List:** `[3, 1, 2]`

**Pass 1 (i = 0):**
- Compare index 0 (`3`) and index 1 (`1`). Since `3 > 1`, swap them.
  - List becomes: `[1, 3, 2]`
- Compare index 1 (`3`) and index 2 (`2`). Since `3 > 2`, swap them.
  - List becomes: `[1, 2, 3]`
- End of Pass 1. The largest number (`3`) is now at the end.

**Pass 2 (i = 1):**
- Compare index 0 (`1`) and index 1 (`2`). Since `1 < 2`, no swap needed.
  - List remains: `[1, 2, 3]`
- End of Pass 2. The list is already sorted.

**Pass 3 (i = 2):**
- The inner loop range becomes `range(0)`, so it doesn't run. This is an optimization; the code stops checking once the end is guaranteed to be sorted.

### Final Output:
The function returns the sorted list:
`[1, 2, 3]`
