This code implements the **Bubble Sort** algorithm. It sorts a list of numbers in ascending order by repeatedly swapping adjacent elements if they are in the wrong order.

### How it works (Plain English):
Imagine you have a row of people, and you want them lined up from shortest to tallest. You walk down the line looking at neighbors:
1. If the person on the left is taller than the person on their right, you swap them so the shorter one is now on the left.
2. You keep walking down the line until you reach the end.
3. Then, you go back to the very beginning and repeat the process.
4. You keep doing this round after round until no more swaps are needed. At that point, everyone is perfectly sorted.

The nested loops in the code simulate this exact behavior:
- The outer loop (`i`) controls how many "passes" through the list we do.
- The inner loop (`j`) checks every pair of neighbors and swaps them if they are out of order.

### Input: `[3, 1, 2]`

Let's trace the execution step-by-step:

**Initial List:** `[3, 1, 2]`

**Pass 1 (Outer loop `i = 0`):**
- Check index 0 and 1: Is `3 > 1`? **Yes**. Swap them.
  - List becomes: `[1, 3, 2]`
- Check index 1 and 2: Is `3 > 2`? **Yes**. Swap them.
  - List becomes: `[1, 2, 3]`
- End of Pass 1. The largest number (3) has "bubbled up" to the end.

**Pass 2 (Outer loop `i = 1`):**
- Check index 0 and 1: Is `1 > 2`? **No**. No swap needed.
- End of Pass 2.

Since no swaps occurred in the second pass, the list is already sorted. The algorithm stops early because the inner loop range shrinks, but logically the sorting is complete.

### Final Output:
The function returns:
```python
[1, 2, 3]
```
