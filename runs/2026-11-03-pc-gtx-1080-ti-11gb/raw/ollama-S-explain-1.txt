This code implements the **Bubble Sort** algorithm. It sorts a list of numbers in ascending order by repeatedly swapping adjacent elements if they are in the wrong order.

### How it works (Plain English):
Imagine you have a row of people, and you want them lined up from shortest to tallest. You walk down the line looking at neighbors:
1. If the person on the left is taller than the person on their right, you swap them so the shorter one is now on the left.
2. You keep walking down the line until you reach the end.
3. Then, you go back to the very beginning and repeat the process.
4. You keep doing this round after round until no more swaps are needed. At that point, everyone is perfectly sorted.

The variable `i` controls how many rounds of checking happen (starting from the left), and `j` checks each pair of neighbors in the current round.

### Input: `[3, 1, 2]`

Let's trace the execution step-by-step:

**Round 1 (`i = 0`):**
- **Check index 0 & 1:** Compare `3` and `1`. Since $3 > 1$, swap them.
  - List becomes: `[1, 3, 2]`
- **Check index 1 & 2:** Compare `3` and `2`. Since $3 > 2$, swap them.
  - List becomes: `[1, 2, 3]`

**Round 2 (`i = 1`):**
- The inner loop range is now `range(1)`, so it only checks index 0 & 1.
- **Check index 0 & 1:** Compare `1` and `2`. Since $1 < 2$, no swap happens.
  - List remains: `[1, 2, 3]`

**Round 3 (`i = 2`):**
- The inner loop range is `range(0)`, so the loop doesn't run at all.

The function returns the modified list.

### Final Output
```python
[1, 2, 3]
```
